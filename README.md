# Operação Crachá Geek — Desafio POO I

Este projeto foi desenvolvido para o desafio de Programação Orientada a Objetos (POO).
A classe `Participante` representa uma pessoa inscrita em um evento geek.
Seus atributos privados são nome, e-mail e tipo de participação.
Os métodos `cadastrar()` e `exibir_dados()` permitem confirmar e mostrar os dados.
Também existem métodos getters para consultar os atributos privados.
O programa cria três objetos: Ana (Cosplay), Bruno (Campeonato) e Carla (Palestra).
Cada objeto possui seus próprios dados e é exibido no console.
O projeto foi escrito em Python e demonstra classe, objetos, atributos, métodos e encapsulamento.

## Como executar

1. Tenha o Python 3 instalado.
2. Abra o terminal na pasta do projeto.
3. Execute: `python main.py`
